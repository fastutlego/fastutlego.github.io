시행일: 2026년 10월 8일

모두뷰어(이하 "앱")는 사용자의 기기에 있는 만화책(ZIP·RAR·7z), PDF, 텍스트·문서 파일을 열어 보는 뷰어 앱입니다. 앱은 사용자가 가입하거나 로그인해야 하는 자체 서비스와 서버를 운영하지 않습니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

## 1. 기기 안에만 저장되는 정보

아래 정보는 사용자의 기기 안에만 저장되며 개발자에게 전송되지 않습니다.

- 사용자가 가져온 파일과 서재 정보(제목, 표지, 읽던 위치, 책갈피, 읽기 설정)
- 읽어 주기 설정, 화면 밝기·보기 방식 등 앱 설정
- Google 드라이브 로그인 토큰(기기의 보안 저장소에 암호화되어 보관)

앱을 삭제하면 이 정보도 함께 삭제됩니다. 앱이 만든 백업 파일은 사용자가 지정한 위치에 저장되며, 개발자가 접근할 수 없습니다.

## 2. 수집하는 정보와 이용 목적

앱은 서비스 개선과 오류 수정을 위해 Google이 제공하는 Firebase 서비스를 사용하며, 아래 정보가 Google에 전송됩니다.

| 서비스 | 수집 항목 | 이용 목적 |
|---|---|---|
| Firebase Analytics | 앱 사용 이벤트(책 가져오기·열기·삭제, 읽기 방식 변경, 백업 내보내기·가져오기, 드라이브 다운로드 실패), 화면 이동, 앱 인스턴스 ID, 기기 모델·OS 버전·언어 등 기기 정보 | 기능 이용 현황 파악과 개선 |
| Firebase Crashlytics | 앱이 비정상 종료될 때의 오류 기록(스택 트레이스), 기기 모델·OS 버전, 앱 버전, 앱 인스턴스 ID | 오류 원인 분석과 안정성 개선 |

- 책 제목, 파일 이름, 파일 내용, 오류 메시지 본문 등은 전송하지 않습니다.
- 광고 ID는 수집하지 않으며, 앱에는 광고가 없습니다.
- 전송되는 정보에는 이름·이메일·전화번호 등 사용자를 직접 식별하는 정보가 포함되지 않으며, 암호화된 연결(HTTPS)로 전송됩니다.
- Firebase가 정보를 처리하는 방식은 [Google 개인정보처리방침](https://policies.google.com/privacy)과 [Firebase 개인정보 및 보안](https://firebase.google.com/support/privacy)에서 확인할 수 있습니다.

## 3. Google 드라이브 연동

사용자가 선택하면 Google 계정으로 로그인해 드라이브의 파일을 앱으로 가져올 수 있습니다.

- 요청하는 권한은 **읽기 전용**(`drive.readonly`)입니다. 앱은 드라이브의 파일을 수정하거나 삭제하지 않습니다.
- 사용자가 고른 파일만 기기로 내려받으며, 파일과 계정 정보는 개발자의 서버로 전송되지 않습니다.
- 드라이브 연동은 선택 사항이며, 사용하지 않아도 앱의 다른 기능을 모두 쓸 수 있습니다.
- 사용자는 언제든지 앱에서 로그아웃하거나 [Google 계정 권한 설정](https://myaccount.google.com/permissions)에서 앱의 접근 권한을 취소할 수 있습니다.
- 앱의 Google API 정보 이용은 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)의 제한된 사용 요건을 준수합니다.

## 4. 기기 권한

- **인터넷**: 드라이브 연동과 Firebase 전송에 사용합니다.
- **알림**: 소리 내어 읽어 주기 중 재생 컨트롤을 알림으로 표시합니다.
- **포그라운드 서비스(미디어 재생)·절전 해제 유지**: 화면이 꺼진 상태에서도 읽어 주기를 이어 가기 위해 사용합니다.
- **모션 센서**: 서재 화면의 시각 효과에 사용하며, 센서 값은 저장하거나 전송하지 않습니다.
- 파일은 사용자가 파일 선택기에서 직접 고른 것만 읽습니다. 사진이나 저장소 전체에 접근하는 권한은 요청하지 않습니다.

## 5. 소리 내어 읽어 주기

읽어 주기는 기기에 설치된 Android 음성 합성(TTS) 엔진이 처리합니다. 읽을 텍스트를 앱이 개발자의 서버로 보내지는 않습니다. 선택한 TTS 엔진이 텍스트를 어떻게 처리하는지는 해당 엔진 제공자의 방침을 따릅니다.

## 6. 제3자 제공

개발자는 사용자의 정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. 위 2·3항의 Google 서비스 이용을 제외하고 외부로 전송하는 정보는 없습니다.

## 7. 보관과 삭제

- 기기 안의 정보는 앱을 삭제하거나 앱 데이터를 지우면 삭제됩니다.
- Firebase에 전송된 정보는 Google의 보관 정책에 따라 일정 기간 뒤 삭제됩니다.
- 삭제·열람 등의 요청은 아래 연락처로 보내 주세요. 앱이 사용자를 식별하는 정보를 보관하지 않으므로, 요청을 처리하려면 앱 인스턴스 ID 등 확인에 필요한 정보를 요청드릴 수 있습니다.

## 8. 아동의 개인정보

앱은 만 13세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 의도적으로 수집하지 않습니다.
